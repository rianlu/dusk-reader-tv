## 1. 产品方向与设计哲学

**暮阅是"本地小说版的 Apple TV 流媒体应用"**,不是文件工具。全局遵循 tvOS 式原则:

- **内容优先**:海报/正文是主角,文字说明和功能按钮退后;每屏只突出 1 个主层级,不堆说明文案
- **聚焦态强化,非聚焦态克制**:信息(标题/作者/进度)在聚焦时显现,静息时保持整洁
- **焦点四可**:可预测、可回退、可记忆、不跨层乱跳
- **两种气质,一套语言**:浏览页(首页/书库/详情/传书/设置)是"内容浏览态",阅读页是"沉浸态";风格反差是刻意的,但焦点表现、圆角、面板色一致,切换不突兀

**基准来源**:阅读页(`ReaderScreen` + `ReaderSettingsOverlay`)是被认可的参考实现,其代码即标准;其它页面向它对齐,不反向要求阅读页迎合规格。

## 2. 设计 Token(代码实测,2026-07-20 核实)

### 2.1 颜色

| 角色 | 值 |
|---|---|
| 沉浸铬层面板底(设置抽屉/目录抽屉/选项卡静息) | `0xFF111111` / `0xFF171717` / `0xFF222222` |
| 选中但未聚焦填充 | `White @ 0.14~0.16` |
| 小卡/步进按钮静息底 | `White @ 0.08` |
| **聚焦态** | 白色实底 + 黑色内容 + `2dp` 白描边(全局签名,见 2.4) |
| 静息描边(按钮类) | `1dp` 低透明度白 |
| 控制层遮罩 | 顶 `黑0.78→透明` / 底 `透明→黑0.88` 竖向渐变 |
| 浏览页底色 | 深色硬编码(如 `0xFF05070B`),**允许硬编码**,不强制走 `colorScheme`,只要聚焦表现统一 |
| 铬层文字 | 白色,次级按 `0.92/0.82/0.72/0.66/0.58/0.56` 递减 alpha |
| 阅读主题(4 组) | ForestNight `0xFF101E19` / CinemaGray `0xFF15171A` / WarmParchment `0xFFD8C9AC` / HighContrast `0xFF050607` |

### 2.2 圆角(TV Material 默认 shapes,不设上限)

| 组件 | 圆角 |
|---|---|
| 选项卡 / 主题卡 / 通用按钮(DuskTvButton) | `shapes.large` = 16dp |
| 列表项 / 目录项 / 海报卡 | `shapes.medium` = 12dp |
| chip / 小标签 | `shapes.small` = 8dp |
| 步进 +/- 按钮 | `CircleShape` |
| 全高侧边抽屉 | `RectangleShape`(直角贴边) |

### 2.3 间距(4 的倍数节奏)

- 面板内:水平 `32` 垂直 `28`(设置抽屉)、`24`(目录);分组间 `28`;组内 `24`;标签→控件 `12`;小间隙 `8`
- 控制层:水平 `52` 垂直 `24`;阅读正文呼吸:水平 `72` 垂直 `56`
- 侧抽屉宽:设置 `460dp`、目录 `420dp`;选项卡高 `60dp`、主题卡高 `92dp`、步进按钮 `48dp`
- 卡片比例:书籍海报 `10.5 : 16`;舞台区背景近似 `16 : 7`

### 2.4 焦点交互(签名规范,最重要)

所有可聚焦元件统一「白色反相」:

1. **聚焦 = 白色实底 + 黑色内容 + `2dp` 白描边**(`focusedContainerColor = White` / `focusedContentColor = Black` / `focusedBorder 2dp White`)
2. **聚焦缩放分两档**(当前代码实测):
   - 沉浸铬层组件(阅读设置/目录/控制层)= `focusedScale = 1.04f`
   - 浏览页卡片与通用按钮(`BookCard` / `DuskTvButton` / 书库网格)= `focusedScale = 1f`(仅靠白底反相 + 描边表达焦点;低端盒子上缩放动画是卡顿源,此为性能取舍)
   - 新组件按所在气质选档;不得出现第三种缩放值
3. **选中但未聚焦** = `White @ 0.14~0.16` 轻填充,不抢聚焦表现
4. 可滚动容器内的聚焦项必须挂 `BringIntoViewRequester` + `bringIntoView()`,保证滚入视野
5. **显式焦点图**:`focusProperties { up/down/left/right }` 明确邻居;边界用 `FocusRequester.Cancel` 封口防逃逸;侧抽屉整体 `left/right = Cancel`
6. 列表/网格挂 `focusRestorer()` 记忆并恢复焦点;首焦用 `createInitialFocusRestorerModifiers()` 模式
7. 聚焦后允许显现辅助信息(标题/作者/进度),静息态收敛

### 2.5 排版

- **阅读正文**:`FontFamily.Serif`、`TextAlign.Justify`、`letterSpacing 0.4sp`、`lineHeight = fontSize × lineSpacing`、字号 `18–80px`、极轻文字阴影。正文衬线是刻意的,与铬层区分
- **铬层/浏览页**:全局 `Inter` type scale——面板标题 `headlineSmall(24)` 加粗、书名 `titleLarge(22)` 加粗、分组标签 `titleMedium(16)`(白 0.72)、辅助 `labelLarge/Medium/Small`、说明 `bodySmall`

### 2.6 动效

- 阅读主题切换:背景/文字色 `320ms tween` 渐变
- 覆盖层:控制层上/下 `slide + fade`;设置层右侧滑入、目录层左侧滑入,退出反向
- **不做花哨动画**;任何新增动效先在低端盒子验证帧率,卡顿则砍

## 3. 页面结构规范

### 3.1 导航结构

- 外层 NavHost:`Dashboard → BookDetails/{bookId} → Reader/{bookId}`
- Dashboard 内层 Tab:`首页 · 书架 · 传书 · 设置`(书源启用后插入「找书」,见书源文档)
- 首页与书库是 **`BookshelfScreen` 双模式复用**(`BookshelfScreenMode.Home/Library`),不存在独���的 home/library 包
- 返回键约定:逐层回退(覆盖层 → 页面 → Tab → 退出确认),各页不得自创返回语义

### 3.2 浏览页统一骨架

顶部导航层 → 内容舞台层 → 内容列表层。不用"工具卡片堆叠",以整块内容带组织信息。

- **Dashboard 顶栏**:轻量、服务内容;选中态与聚焦态需可见区分(白色胶囊指示器);内容滚动时可弱化但不突然消失
- **首页(Home 模式)**:顶部舞台区(聚焦书籍的背景 + 书名/作者/进度/主按钮,背景优先 `backdropPath`,否则封面裁切渐变,再否则默认横图)+ 海报墙行(继续阅读 / 最近导入 / 未开始 / 全部);空状态给「前往传书」
- **书库(Library 模式)**:顶部一行轻筛选条(排序 / 格式 / 搜索)+ 大海报网格为主视觉;不出现大块说明卡
- **详情页**:背景氛围层 + 左海报 + 右侧标题/作者/元数据/主操作;主按钮只有「开始阅读 / 继续阅读」;避免"文件属性面板"感
- **传书页**:设备连接页气质——二维码与地址为主视觉,状态与最近上传为辅,文案短
- **设置页**:分组入口行列表(标题 + 副标题 + 箭头),聚焦白底反相;已接 ViewModel(重扫书库等真实动作)

### 3.3 封面与默认资源

- 优先级:本地真实封面 → EPUB 内嵌封面 → 在线解析(OpenLibrary)→ 生成式封面兜底(`GeneratedCoverFactory`)
- `coverPath` 竖版海报 / `backdropPath` 横版背景;默认资源必须保持流媒体质感,不用随机高饱和渐变

### 3.4 阅读页(沉浸态行为规格)

- **单页全屏**正文,`HorizontalPager` 承载、`userScrollEnabled = false`,纯方向键驱动;沉浸态 = 无控制层/目录/设置
- 翻页:`PageTurnMode` 三种——HORIZONTAL(左右键)/ VERTICAL(上下键)/ AUTO(定时,`AutoTurnInterval`)
- `DPAD_CENTER/ENTER`(沉浸态)呼出控制层:顶部书名/章节/进度/时间,底部目录/设置/退出
- **分层返回**:目录 → 关目录;设置 → 关设置回控制层;控制层 → 关闭回沉浸;沉浸 → 退出阅读
- 目录 = 左侧抽屉(跳章后回阅读态);设置 = 右侧抽屉,**即时生效**(无草稿/确认/取消),调整立即应用并持久化(`ReaderSettingsStore`),字号/行距变化自动重新分页
- 设置项:字号、行距、段距、翻页方式、自动翻页间隔(仅 AUTO 显示)、4 组主题、文字亮度 3 档
- 分页基于**实际渲染区域尺寸**(禁止写死 1920×1080),后台线程 `TextMeasurer`;重新分页保持进度比例;进度按 `(lastReadChapter, lastReadPosition)` 存储,对字号变化不变
- 阅读页验收底线:打开、翻页、跳章、调设置、退出、进度恢复六项,任何改动必须全部回归

## 4. 全局工程约定

- 全部 TV UI 用 `androidx.tv.material3`,**无 Leanback**
- D-pad 处理走 `ModifierUtils.handleDPadKeyEvents`;新页面不得自创按键分发
- 焦点、返回键、聚焦样式必须复用 §2.4 与 §3.1 约定,禁止页面各自发明
- 修改浏览页数据结构时,首页与书库(同一 `BookshelfScreen`)必须同时验证
- 传书相关改动要同时检查 `FileTransferServer`(真正的上传逻辑所在)与书库扫描
- "页面没数据"先排查存储权限与扫描,再动 UI

## 5. 已知偏差与待办(2026-07-20 快照,动手前重新核实代码)

1. **书架性能**:全量内存过滤 + `LIBRARY_LIMIT = 240` 静默截断待重构(下沉 Room 查询);搜索无 debounce
2. **筛选交互**:`cycle*()` 循环点按切换选项属反模式,应改为选项可见的筛选行
3. 传书内嵌 Ktor 服务 `@Singleton` 从不 `stop()`,离页后仍常驻 8080
4. 详情页元数据与管理动作(删除书籍/重新解析)仍偏少
5. 顶栏选中态 vs 聚焦态区分度弱
6. 全页面焦点走查(初始焦点、`focusRestorer`、边界封口)未系统化验证
